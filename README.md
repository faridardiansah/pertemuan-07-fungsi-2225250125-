## Deskripsi
Program Utilitas Matematika Modular merupakan program Python berbasis menu yang menyediakan beberapa operasi matematika sederhana. Program ini dibuat menggunakan fungsi, parameter, perulangan, seleksi kondisi, dan `return`.

## Tujuan
1. Memahami cara membuat dan menggunakan fungsi dalam Python.
2. Memahami penggunaan parameter dan nilai kembali (`return`).
3. Menerapkan perulangan dan seleksi kondisi.
4. Membagi program menjadi beberapa fungsi dengan tugas yang jelas.
5. Melakukan validasi input pengguna.

## Fitur Program
Program menyediakan empat operasi matematika:
1. Menghitung luas persegi panjang.
2. Menghitung luas segitiga.
3. Menghitung jumlah bilangan dari 1 sampai n.
4. Menghitung faktorial bilangan n.

Program juga menyediakan pilihan untuk keluar dan menangani input yang tidak valid.

## Cara Menjalankan
1. Buka folder proyek di Visual Studio Code.
2. Buka terminal.
3. Jalankan perintah berikut:

```bash
python3 praktik/utilitas_matematika.py
```

4. Pilih menu dengan mengetik angka 1, 2, 3, 4, atau 0.
5. Masukkan angka sesuai petunjuk yang muncul di terminal.
